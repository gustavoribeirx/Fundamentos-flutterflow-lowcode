# Fundamentos FlutterFlow (Low-Code)

Este repositório apresenta os conceitos fundamentais do FlutterFlow, explorando o desenvolvimento de aplicações por meio da abordagem low-code.

## Sobre o Projeto

Projeto voltado para estudo e introdução ao FlutterFlow, uma ferramenta que permite criar aplicativos mobile e web de forma visual, reduzindo a necessidade de programação tradicional.

## O que é FlutterFlow

FlutterFlow é uma plataforma baseada no Flutter que possibilita a criação de aplicativos através de uma interface gráfica, com recursos como:

- Criação de interfaces por drag and drop  
- Integração com APIs e bancos de dados  
- Exportação de código Flutter  
- Desenvolvimento para Android, iOS e Web  

## Conteúdo

- Introdução ao low-code  
- Criação de interfaces  
- Navegação entre telas  
- Integração com backend  
- Boas práticas  

## Objetivo

Facilitar o aprendizado de desenvolvimento low-code e auxiliar na criação de aplicações de forma rápida e prática.

## Como Utilizar

1. Explore os arquivos do repositório  
2. Reproduza os exemplos no FlutterFlow  
3. Teste e modifique as funcionalidades
